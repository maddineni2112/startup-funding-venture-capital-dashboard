# Startup Funding and Venture Capital Analytics Dashboard

**Timeline:** December 2025  
**Category:** Main project

This project cleans, transforms, and explores startup-funding records for interactive venture-capital analysis. The dashboard code separates data preparation, layout, callbacks, and application startup so the analysis can be extended with new views.

## Stack

Python, Pandas, Dash, Plotly, Tableau, D3.js, JavaScript, HTML/CSS, and exploratory data analysis.

## Repository contents

- `src/app.py`, `src/data.py`, `src/callbacks.py`, `src/layouts.py` — dashboard application modules.
- `data/startup_companies_sample.csv` — small demonstration sample only.
- `reports/` — visualization project documentation.
- `data/README.md` — source and excluded-data notes.
