# Data statement

The dashboard was built from a startup-funding dataset used in the UNT scientific data visualization coursework. Raw records are excluded because the full dataset is large and its redistribution terms are not established here. A small sample is included only to document the expected schema.

The local working data was stored under `Documents/UNT/SDV/startup_dash`. Obtain the source dataset from the authorized course/source location, then update the application input path. Expected fields include company/startup identity, funding amount, category/industry, geography, and date or stage attributes when available.
